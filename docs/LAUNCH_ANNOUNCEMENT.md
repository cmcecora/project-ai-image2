# Launch Announcement - AI or Not?

## Overview

"AI or Not?" is an engaging web game that challenges players to distinguish between real photographs and AI-generated images. Test your perception skills and see how you rank against players worldwide!

---

## 🎮 Game Features

### Core Gameplay
- **Simple & Addictive**: Look at an image, guess if it's AI or real
- **Instant Feedback**: See if you're correct immediately
- **Real Statistics**: View how other players voted on each image
- **Global Leaderboard**: Compete with players worldwide
- **Streak System**: Build combos for higher scores

### Interactive Elements
- **Swipe Gestures**: Mobile-friendly swipe controls (swipe right for AI, left for Real)
- **Keyboard Shortcuts**: Quick navigation with keyboard (Y/N, Arrow keys, Enter/Space)
- **Haptic Feedback**: Tactile responses on mobile devices
- **Smooth Animations**: Polished transitions and celebrations

### Visual Design
- **Modern UI**: Clean, gradient-based design
- **Responsive**: Perfect on desktop, tablet, and mobile
- **Dark Mode Ready**: Eye-friendly interface
- **Confetti Celebrations**: Rewarding animations for correct answers
